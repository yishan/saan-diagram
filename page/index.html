Saan Kits

把需求变成图示、文档和原型的 Agent 技能集。每个技能都能单独安装。

  • Saan Diagram

    把业务描述、需求文档和白板截图，转成同一套规范下的中英文业务图。

    适合汇报、对外交付和飞书画板，可导出 HTML、SVG 和 PNG。

    npx skills add yishan/saankits --skill saan-diagram
    查看图示类型、示例和依赖

  • Saan Mermaid

    用 Mermaid 画图，并拿一份独立的控制点清单审查业务流程。

    适合放进 Markdown 和设计文档的图，以及审批流程审查。

    npx skills add yishan/saankits --skill saan-mermaid
    查看审查规则、示例和依赖

  • Saan Discovery

    先确定 ToC、ToB/G 或混合调研范围，再结合已有产品逐项追问、整理证据和判断适配。

    交付访谈提纲、专题纪要和补问清单。中文请求默认使用中文交互与产出。

    npx skills add yishan/saankits --skill saan-discovery
    查看调研方式、示例和安装方式

  • Saan PRD Writing

    根据需求与原型编写完整规格或局部变更，写清条件、字段、状态与处理结果。

    交付 PRD、验收场景和待确认事项，附带中英文模板及写作示例。

    npx skills add yishan/saankits --skill saan-prd-writing
    查看文档结构、示例和安装方式

计划中：原型。

全部安装

npx skills add yishan/saankits

安装时可以选择技能和目标 Agent。之后新增的技能需要再次安装。各技能的依赖见它们的介绍页。
