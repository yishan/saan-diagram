Saan Kits

Skills for everyday work: think through a problem, reverse-engineer an existing system, prepare research, write requirements, build a review prototype, or draw a business diagram. Choose what you need and install it in your AI assistant.

7 skills

  • Saan Diagram

    Use documents or whiteboard screenshots to explain a business, system, or process with architecture diagrams, flowcharts, and swimlanes.

    Keep functions, roles, and systems distinct, with consistent layout and colors. Save a web page or image, or write to a Feishu/Lark whiteboard. Keep the source for later edits.

    npx skills add yishan/saankits --skill saan-diagram
    See diagram examples and how to use them

  • Saan Mermaid

    Add diagrams to Markdown, READMEs, or design documents, then update them by editing text. Draw workflows, system interactions, record states, and schedules.

    With an approval checklist, check for missing steps, paths that bypass a required review, and decisions with no return path.

    npx skills add yishan/saankits --skill saan-mermaid
    See diagrams and workflow checks

  • Saan Discovery

    Prepare questions before an interview, then organize what people do, where they struggle, and what still needs asking. Use it for consumer, business, or public-service research.

    If you have an existing product, compare it with customer needs and identify what still needs checking. Save the work as an interview guide, research notes, or follow-up questions.

    npx skills add yishan/saankits --skill saan-discovery
    See how to prepare and organize research

  • Saan PRD Writing

    Bring requirements, review notes, and prototypes together in a document your team can discuss. Start with a whole project or describe just the feature being changed.

    Explain who can act, what they enter, what changes, and what happens on failure. Include acceptance scenarios and list decisions that are still open.

    npx skills add yishan/saankits --skill saan-prd-writing
    See the document structure and a worked example

  • Saan Prototype

    Give the team a prototype to try before development. Switch roles to see who can act, what changes when an action succeeds, and what the screen shows when it fails.

    Open questions and proposed wording are marked on the relevant screens. Bring one HTML file to the review and open it offline in a browser.

    npx skills add yishan/saankits --skill saan-prototype
    Try the example prototype

  • Saan Inquiry

    Start a conversation when a problem is hard to describe or a choice is hard to make. Separate what you know from what you suspect, and consider other explanations.

    Once you have enough to decide, bring the discussion together and choose a next step. Return with the results to see what changed.

    npx skills add . --skill saan-inquiry
    See conversation examples and local installation

  • Saan X-Ray

    Walk through an existing live system, codebase, or UI screenshots to understand what a project actually does today—in plain product language rather than a raw file tree.

    Get a 5-minute System Overview Briefing first, with observed facts kept distinct from inferences and blind spots, then drill into As-Is module specifications on demand.

    npx skills add yishan/saankits --skill saan-xray
    See the two-pass workflow and safety modes
