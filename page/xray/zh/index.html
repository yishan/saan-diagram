Saan X-Ray

v0.1.0

接手存量系统或历史项目时，先用产品和业务语言看清它现在到底做什么、怎么运转。

可以指向运行中的界面（通过浏览器或 Computer Use）、项目代码库或界面截图。它不会一上来堆砌文件目录树，而是先交付一份几分钟就能读完的系统概览简报；需要改某个模块时，再按需下钻字段、校验规则和状态流转表。

先给全景简报，再按需深挖模块

Pass 1：系统概览简报（默认必交）

第一轮默认控制信息密度，用业务语言建立全局心智模型，不把框架样板代码当结论：

  1. 系统定性与本次透视覆盖范围
  2. 角色与入口视图（≤4 类角色/端）
  3. 模块与功能地图（按 模块 → 功能 组织，≤6 个模块）
  4. 2–4 条端到端核心业务主线
  5. 核心业务对象与已确认状态流转（≤5 个对象）
  6. 界面与代码差异、待核实盲区

Pass 2：模块现状规格（按需下钻）

选定要改版或深究的模块后，提取直接对齐 Saan PRD Writing 的现状基线：

  1. 页面区域、筛选项、列表列与表单字段清单
  2. 校验规则、边界条件与报错提示
  3. 集中定义的状态流转表（当前状态 × 触发动作/角色/条件 → 目标状态）
  4. 待确认事项（OQ-*），可直接转入局部变更或完整 PRD

安全走查运行界面、代码库或混合来源

  • 运行界面（浏览器 / Computer Use）：默认采用 Observe-only（只读漫游）——只切换菜单、标签页、列表筛选项和只读详情，打开新建弹窗读取字段后取消关闭，不点击保存、提交、删除、审批、支付或发送；仅在明确授权测试环境与测试账号时才启用 Sandbox / Test-walk。
  • 项目代码与接口定义：从路由表、领域模型、状态枚举、权限守卫和定时任务提取业务规则，自动略过构建配置与通用 UI 样板。
  • 界面与代码交叉印证：同时具备界面和代码时，主动标出“代码里有但界面藏掉的隐藏功能”、“界面有按钮但未接线的空壳”以及“界面文案与底层枚举的术语映射”。

单看界面或单看代码容易漏掉的事实

仿真评测案例 · 存量差旅与日常报销系统

“我们刚接手这套遗留报销系统，历史文档找不到了。请以只读模式（Observe-only）结合员工端页面与 server.py 做一次透视。”
  1. 发现隐藏的二级审批状态：员工端状态筛选器只有 6 个选项，但后端 server.py 定义了第 7 个状态 MANAGER_OK——单笔超过 5,000 元经部门经理通过后，会转入待 CFO 复核。
  2. 识别前端空壳与后台定时任务：列表顶部的“导出 PDF”按钮只是未接线的占位符（onclick="return false;"），而每天凌晨 02:00 的定时任务会自动归档超过 14 天未补件的退回单据。
  3. 下钻模块现状规格：继续对“我的报销单”执行 Pass 2，即可提取完整的 7 状态流转矩阵、表单校验先后顺序与 6 项待业务拍板问题（OQ-001～006），直接交接给 Saan PRD Writing。

完整的双阶段评测样本与输出结果保存在仓库的 tests/saan-xray/ 目录中。

把实测事实、合理推断和盲区分开

证据标记含义处理方式
[Observed-UI]在运行界面、DOM 状态或截图中直接看到的表现记录为已确认界面事实，并注明页面或路由
[Observed-Code]在路由、模型、校验逻辑或定时任务中确认的实现用业务语言表述规则，附上文件或接口引注
[Inferred]由局部线索推断（如筛选下拉框有某状态但未触发过）与已确认规则分开列出，并说明核实办法
[Unobserved]受限于当前账号权限、环境或线下制度而未覆盖的部分在盲区清单中显式列出，不靠常识暗中补齐

在 Saan Kits 工作流中的位置

当手头只有存量系统、测试环境或代码库时，先用 Saan X-Ray 摸清现状，再把结果交给其他技能继续推进：

  • 交接 Saan PRD Writing：把 Pass 2 的模块现状规格与状态流转表作为改版需求（change）或二期规格书的现状基线。
  • 交接 Saan Diagram 或 Saan Mermaid：把梳理出的模块地图、跨角色泳道、数据实体关系或单据状态机画成业务图。
  • 交接 Saan Discovery：把 [Inferred] 与 [Unobserved] 的业务盲区转为面向业务方或产品负责人的核实提纲。

开始使用

从 Saan Kits 单独安装 Saan X-Ray：

npx skills add yishan/saankits --skill saan-xray

先让它输出一份系统概览简报：

用 saan-xray 透视当前项目（如果提供了测试环境地址，请以 Observe-only 只读模式走查界面）。先给我一份系统概览简报：用业务语言讲清系统定位、角色入口、模块与功能地图、核心业务主线、核心业务对象与状态流转，以及未覆盖的盲区。

本技能为纯文本包，复用 Agent 当前可用的文件读取、浏览器或 Computer Use 工具。
