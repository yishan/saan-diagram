Saan Kits

整理日常工作中用得上的技能：梳理问题、准备调研、编写需求、绘制业务图。按眼前的任务选一个，装到你使用的 AI 助手里。

5 个技能

  • Saan Diagram

    需要讲清一套业务、一个系统或一段流程时，把文字材料或白板截图交给它，整理成架构图、流程图、泳道图等业务图。

    图中会区分功能、角色和系统，统一排版与配色。可保存为网页或图片，也可写入飞书画板，保留源文件方便后续修改。

    npx skills add yishan/saankits --skill saan-diagram
    查看图示示例与使用方法

  • Saan Mermaid

    给 Markdown、README 或设计文档配图，修改文字就能更新图。除了流程图，也能画系统交互、单据状态和任务排期。

    有审批要求时，可以一起检查流程是否遗漏必要步骤、能否绕过复核，以及退回后有没有后续处理。

    npx skills add yishan/saankits --skill saan-mermaid
    查看图示示例与流程检查

  • Saan Discovery

    准备访谈时，帮你确定该问什么；拿到记录后，整理实际做法、遇到的困难和还没问清的事。适用于消费者、企业和公共服务调研。

    如果已有产品，还会对照客户的做法，梳理哪些需求可以满足、哪些需要进一步核实。结果可整理为访谈提纲、调研纪要和补问清单。

    npx skills add yishan/saankits --skill saan-discovery
    查看如何准备和整理调研

  • Saan PRD Writing

    把需求说明、评审记录和原型整理成团队能一起讨论的需求文档。新项目可以从整体写起，已有项目也可以只写这次要改的功能。

    逐项说明谁能操作、要填什么、操作后怎样变化，以及失败时怎么处理。附上验收场景，把尚未决定的事项单独列出。

    npx skills add yishan/saankits --skill saan-prd-writing
    查看文档结构与写作示例

  • Saan Inquiry

    遇到一个说不清的问题，或在几个选择之间拿不定主意时，从一段对话开始。它会帮你拆开事实和猜测，看看是否漏掉了别的解释。

    聊到足以做决定时，整理当前判断和下一步；有了新结果，再一起回头看。

    npx skills add . --skill saan-inquiry
    查看对话示例与本地安装方法
