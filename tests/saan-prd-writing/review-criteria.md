# 会议室预约试写评审标准

在独立试写前固定。评估者只收到技能包、fixtures/room-booking 和交付任务，不读取本文件、既有融合分析或预期答案。本标准由主任务用于逐条核对实际产物，不是生成提示。

| 编号 | 核对的行为与边界 |
|---|---|
| C01 | 完整规格覆盖文档控制及六章；功能按模块、业务描述、界面、字段、约束组织。组织形式服务实际信息，不重复维护规则。 |
| C02 | 既有门户登录、身份和会议室资料属于边界；不扩展到资料管理、审批、周期预约、跨办公点、签到、收费或本期统计。 |
| C03 | 明确的评审决定覆盖审批讨论选项；即时占用为唯一有效方案。24/2 小时意见保留为未决冲突，改期提前量也未确定。 |
| C04 | 保留 Asia/Shanghai、同日、半小时刻度、09:00—18:00、开始小于结束；不发明预约跨度或数量上限。 |
| C05 | 半开区间允许 09:00—10:00 与 10:00—11:00 相邻；重叠被拒绝；新预约并发最多一个成功。验收检查覆盖边界而非仅检查章节。 |
| C06 | 改期可更换房间/日期/时间但不修改主题；不与原预约自身冲突；成功释放旧占用，失败保留原房间/日期/时段/有效状态。 |
| C07 | 预约人限本人尚未开始的有效预约；已开始、已取消分别保留约束。取消后的记录保留在我的预约。 |
| C08 | 管理员只取消所管房间尚未开始的有效预约、原因必填；不取得替他人改期或修改历史的权限。普通员工原因要求保持未知。 |
| C09 | 主题仅预约人和所管房间管理员可见，其他员工看到已占用；不要扩大到所有管理员，也不要以隐藏按钮代替提交检查。 |
| C10 | 停用会议室不能新预约或成为改期目标；已有预约处理、原因查看/保留、通知/重试等未决项保留，不推定自动取消或固定时限。 |
| C11 | 不继承模板固定性能/可用性/安全等级/技术栈/服务承诺；无视觉稿、实际评审与业务验收的证据边界明确。 |
| C12 | 界面建议文案与确定标签区分；规则、字段、状态、验收可对应，验收不注入未知提前量、失败语义或服务指标。 |

通过判定依据实际内容和数据效果，不依赖固定措辞、段落长度或编号数量。单个模拟需求验证不证明真实业务验收或优于无技能基线。
