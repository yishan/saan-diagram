# Saan Inquiry

[English](README.md) | **简体中文**

通过自适应对话把模糊问题想清楚，探索可能的解释和遗漏视角，形成有依据的判断与下一步。技能版本 **0.1.0**，本地初版；远程安装与线上站点以实际发布为准。

## 适合什么任务

可以从一个没想清楚的念头、笼统判断、难做的选择，或与预期不符的结果开始。适用于产品、业务、团队协作、学习和日常决策。技能会根据当前需要选择追问、解释、换个角度、综合或建议小实验，不要求填完问卷，也不保证找出所有盲点或唯一根因。

`saan-discovery` 侧重客户调研、访谈准备和产品适配，`saan-prd-writing` 负责需求文档；Inquiry 侧重与用户共同思考。有明确交付物时可以选用其他技能，但均非必需依赖。已经说清楚的执行任务不应被强行改成访谈。

## 使用本地技能包

在包含本版本的仓库根目录执行：

```bash
npx skills add . --skill saan-inquiry
```

也可以把完整的 `skills/saan-inquiry/` 复制到目标 Agent 的技能目录。核心为文本对话，无外部服务、脚本运行环境或其他技能依赖；读取外部资料需要相应工具。本次编写不会自动安装到用户全局目录。

统一指令入口使用英文，实际对话优先采用用户指定语言，否则沿用请求语言。

## 怎样开始和控制节奏

```text
用 saan-inquiry 帮我想清楚：为什么读书会活动最近总临时取消？
我怀疑是分工不清，但还不能确定，也想看看漏掉了哪些因素。
```

可以随时说：

```text
这个我不知道。先用已有信息给一个暂定的下一步。
```

```text
先别继续问了，把目前的判断、假设，以及什么情况会改变判断整理出来。
```

拿到结果后继续：

```text
我们按上次的办法试了，中间指标改善了，但原来的问题还在。
帮我对照预期看哪里需要修正，以及接下来怎么做。
```

## 对话应该带来什么

问题应能影响判断或行动，复用上下文，一次通常只聚焦一个重点。不知道的内容不会靠猜补齐，原因先作为待验证解释。盲点按相关性提出，说明为什么值得关注，不要求覆盖所有维度。

需要综合时，可以简洁整理为：当前理解、关键未知、下一步行动或观察、回看的结果或触发条件。只需要澄清一句话时，就交付一句话。计划验证仍是待执行；试验执行了，也不等于原问题已经解决。

技能提出下一步不代表获得外部执行授权，也不会仅因建议回看而创建提醒。普通对话默认不创建文件；用户要求或任务本身需要时才保存可续接的思考记录。
