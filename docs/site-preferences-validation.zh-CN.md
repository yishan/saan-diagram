# 介绍页语言与外观验证

日期：2026-11-04。范围：Discovery v0.2.0、PRD Writing v1.0.0 与 Saan Kits 1.1.0 集合页面。

## 当前规则

两份 `SKILL.md` 使用英文作为指令入口。技能交互与交付物仍优先采用用户指定语言，否则沿用请求语言。

首页、Diagram、Mermaid、Discovery 和 PRD Writing 五个页面均预置英文与中文。首次进入主入口时使用浏览器首个支持的语言，未匹配时回退英文；手动选择优先并保存在当前浏览器。右上角使用语言和外观两个图标按钮，分别打开中英文和系统／浅色／深色下拉菜单；菜单标出当前选择，外观图标反映已选模式。首次主题跟随系统；用户可以选择浅色、深色或重新跟随系统。直接访问各页面的 `/zh/` 保留中文，显式 `?lang=` 选择优先。Diagram 与 Mermaid 的源码和图片示例保留源文件语言，介绍正文及控件文案提供双语。

## Discovery 与 PRD Writing 首次验证

使用本机 Chrome 的无登录临时上下文，完成 14 组检查记录：

- 两个技能分别使用 `zh-CN`、`en-US`、`fr-FR` 浏览器设置：中文、英文、未匹配回退英文均符合规则。
- 系统明暗变化实时生效；手动浅色或深色覆盖系统；刷新和跨技能导航保留选择；重新选择系统后恢复跟随。
- 手动语言选择在两个技能间保留；切换时保留查询参数和当前章节锚点，包括页面加载后才改变的锚点。
- 两种语言分别在 1280、390、320 px 视口检查。控件位于标题上方右侧，无页面级横向溢出；已查看桌面、手机与深色截图。
- 两个技能、两种语言的实际安装命令复制与剪贴板读回一致。受控拒绝复制后，完整请求文本进入手动复制区。
- 禁止 `localStorage` 访问时，语言切换和刷新仍通过 URL 生效，当前页面的主题选择可用。存储不可用时不承诺跨页记忆。
- 显式中文地址保持中文；禁用 JavaScript 后，完整 HTML 与普通语言链接仍可用，主题按钮隐藏，CSS 继续响应系统主题。
- 页面 JavaScript 异常和站内失败资源均为零。

`check_site.py` 检查七个页面和既有 Diagram/Mermaid 示例一致性通过；两个脚本通过 Node 语法检查。两份技能通过 frontmatter 检查，137 个相对文档链接均可解析。

本机已缓存的 skills CLI 列出四个技能。直接 `npx` 查询因环境内 npm DNS 不可用失败；没有把该失败记作通过，也没有为此修改安装说明。

PRD Writing 的 9 个技能文件及归档试写结果与原模拟 manifest 摘要一致。Discovery 五份内部参考与 v0.2.0 模拟时一致；入口只展开英文术语和 UI 简介。既有模拟结果保留，本次未重跑行为模拟。
