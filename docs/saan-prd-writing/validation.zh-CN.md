# Saan PRD Writing 创建与验证记录

日期：2026-11-04。技能版本：1.0.0。

已完成技能包、四份中英文模板、一个包内示例，以及一个独立新需求的实际试写。技能已加入本地 Saan Kits 目录、插件描述和站点源码。没有据此声明远程发布、用户级安装或真实业务验收完成。

## 实现与融合范围

- 英文 `SKILL.md` 承载通用流程与规则表达；默认自动选择保持开启，输出遵循用户语言。
- 完整规格按文档控制、六章正文及必要附录组织。功能单元采用模块 → 业务描述 → 界面设计 → 业务字段 → 功能约束。
- 中英文均有完整规格和局部变更模板。小变更引用已有基线，不强制展开六章。
- 来源读取边界、原型提取、冲突和不确定性处理放入按需参考文件。
- 包内「采购申请批量归档」示例保留虚构输入、具体规则、取消与失败的区分，以及验收对应关系。
- 原始 `.rp`、Word 文件、私有地址、完整提取文本与项目业务数值没有进入可安装包。

## 新需求实际试写

采用独立 Agent 的新上下文。它只获得独立复制的技能包、[会议室预约需求输入](../../tests/saan-prd-writing/fixtures/room-booking/request.md)及两份原始业务材料。它没有获得融合分析、评审标准或预期答案，只能在临时目录中生成文件。

[评审标准](../../tests/saan-prd-writing/review-criteria.md)在生成前固定。主任务保留并逐条核对[原始 PRD](../../tests/saan-prd-writing/results/2026-11-04/room-booking/prd.md)，没有修改产物后再报告通过。

实际产物包含六章主体、六个功能单元、20 条功能规则、22 个验收场景、14 项集中待确认事项。[逐项评审](../../tests/saan-prd-writing/results/2026-11-04/room-booking/review.md)的 12 项标准均通过，主要观察如下：

| 核对内容 | 实际表现 |
|---|---|
| 章节与表达逻辑 | 先说明背景、系统边界与功能关系，再展开界面、字段和处理规则；共用时间及冲突规则集中定义 |
| 时间边界 | 保留 Asia/Shanghai、同日、半小时刻度及 09:00—18:00；相邻时段不被误判为冲突 |
| 并发与改期 | 新预约并发最多一个成功；改期排除原预约自身占用，失败保留原会议室、日期、时间和有效状态 |
| 角色和隐私 | 管理员限所管会议室，未获得替他人改期的能力；主题仅预约人及对应管理员可见 |
| 来源冲突 | 已确认的即时占用替代审批选项；24/2 小时提前量仍为未决，不把较新材料中的讨论意见当作决定 |
| 未知与建议 | 停用后既有预约、原因访问和保存期限、通知重试等保持待确认；建议 UI 文案与四个已确认词区分 |
| 验收与状态 | 验收检查引用既有规则，未通过验收表新增指标；文档明确只是草稿，未进行实现或业务验收 |

未发现需要修改技能的行为失败，因此本轮没有调参或复测。最终技能文件与试写时使用的文件逐一哈希一致。来源和产物哈希保留在 [manifest.json](../../tests/saan-prd-writing/results/2026-11-04/room-booking/manifest.json)。

## 验证限制

- 只覆盖一个新的中文完整规格场景，不能据此推断所有行业、材料规模或语言下的效果。
- 包内采购归档是已知的写作示例，不作为独立测试样本计数。
- 没有无技能对照，因此不作效果优于基线的结论。
- 未在真实业务中执行预约、权限检查、并发处理或用户验收。
- 未验证任意 `.rp` 版本的通用解析、Word/PDF 导出、远程安装、skills.sh 收录或在线站点发布。

新需求产物可直接用于审阅写作质量；进入实施前仍需业务方解决文中影响实现和验收的待确认事项。

## 介绍语言调整（2026-11-04，历史记录）

后续用户明确要求介绍页按浏览器语言选择中英文，并提供主题图标切换。当前规则见 [站点维护说明](../../page/README.md)，下述英文默认行为仅描述当时的检查。

按用户要求，将 `/prd-writing/` 的技能介绍改为默认英文，中文通过 `index.zh-CN.html` 按需选择。语言切换采用普通链接，不根据浏览器语言自动改回中文。正文、安装说明、请求示例、导航标签和复制反馈均与所选语言一致。

技能包的 9 个文件与本次调整前逐一哈希一致；`SKILL.md`、技能元数据及主 README 原本已为英文。PRD 仍按用户指定语言输出，未指定时沿用请求语言。此前的试写产物和验证结论保留。

本轮验证：

- `scripts/check_site.py` 检查六个页面及原有示例同步，通过；`node --check page/site.js` 和 `git diff --check` 通过。
- Chrome 中默认入口为英文，切换至中文再返回英文正常；两种页面的语言属性、介绍内容和当前语言标记一致。
- 英文页在 1280×1000、390×844 视口，中文页在 390×844 视口均无页面横向溢出；已查看截图。
- 英文和中文请求示例均实际点击复制并读回一致，状态分别显示 `Copied` 与「已复制」。英文首次读取曾得到旧剪贴板内容，返回英文页重新复制后读回正确内容，未将旧值记为通过。
- 页面控制台未发现错误，临时视口已恢复。截图保存在本地忽略目录 `out/prd-writing-language/`。

本轮只验证介绍语言与相关页面交互，没有重新执行需求试写，也没有发布在线站点。
