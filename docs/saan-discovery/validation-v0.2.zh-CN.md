# Saan Discovery v0.2.0 验证记录

> 本文件记录模拟执行时的 v0.2.0 快照。后续英文介绍与发布准备仅调整入口术语及 UI 简介；本记录和原始 manifest 保留原样，后续检查见 [发布准备验证](validation-release.zh-CN.md)。

日期：2026-11-04（Asia/Shanghai）。本次更新增加交互式逐专题补充、ToC / ToB/G / 混合场景分流，以及按专题组织的产出。访谈方法仍在技能内部；未拆出新技能。

## 验证方式

将完整技能复制到独立临时目录，以三个独立上下文执行模拟任务。ToC 和公共服务场景分别进行三轮同上下文对话；ToB 场景执行一次直接整理任务，共七次任务响应。执行代理只读取独立技能包、当前用户请求及对应原始材料，没有读取评审标准或预期答案。

主代理检查实际保存的回复和产物，再归档到 [运行记录](../../tests/saan-discovery/results/2026-11-04-v0.2/)。原始对话输入与输出均保留；[manifest.json](../../tests/saan-discovery/results/2026-11-04-v0.2/manifest.json) 记录技能摘要、场景及验证边界。执行时的独立技能与最终七个技能文件摘要一致。

所有案例和业务材料均为模拟。历史飞书调研仅用于本轮之前的风格分析，其原文、企业记录和访问凭据未加入技能或本次测试。

|---|---|---|

本次样本未发现需要修改已测试技能指令的问题。对话会先建议一个简短提纲，后续逐项补充；“一次一个主要问题”并不要求每轮回复只能有一句话。

## 结构与本地页面检查

- `quick_validate.py` 验证技能 frontmatter 和命名通过。
- 技能包内引用、UI 元数据、文档本地链接及 JSON 结构检查通过。
- 独立技能副本与当前源文件逐文件摘要一致；本次没有重新执行安装器或安装到用户级目录。
- `scripts/check_site.py` 的四个页面及原有图示示例一致性检查通过。
- 使用本机 Chrome 的无登录临时浏览器检查本地介绍页：1280×1000 和 390×844 两个视口均无页面级横向溢出，三个调研类型和 v0.2.0 文案可见；新请求示例复制后读回一致，总览与详情往返导航正常，页面未抛出 JavaScript 异常。
- 浏览器初次使用 Playwright 默认浏览器时发现本机未缓存对应版本；改用已安装 Chrome。沙盒阻止启动后，使用获准的本机执行完成检查，没有安装新浏览器。

页面检查数据及截图保存在本地忽略目录 `out/discovery-validation-v02/`。

## 验证边界

- 模拟使用文本问答，没有操作宿主的交互式问题控件。技能保留原生问题界面与普通文本两种方式。
- 未完整重跑 v0.1.0 的所有场景；历史记录和摘要保持原样。
- 未验证真实客户访谈效果、不同人群的代表性或长期使用表现。
- 未做无技能对照；未验证业务制度、产品生产运行或客户验收。
- 尚未执行用户级安装、远程发布或线上站点更新。
