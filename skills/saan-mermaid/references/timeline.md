# timeline

Header: `timeline`. Since 9.4. Example: `assets/examples/timeline.mmd`.

Saan use: milestones by period. No variance or dependency display; use `gantt` for that.

## Syntax

- `title 平台里程碑`
- `第一季度 : 需求确认`, several events: `第二季度 : 合同模块上线 : 数据迁移`.
- `section 名称` groups periods.

## Pitfalls

- Long event text wraps badly. Keep each event to a short phrase.
