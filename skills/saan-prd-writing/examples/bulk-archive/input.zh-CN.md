# 采购申请批量归档｜虚构需求输入

本示例仅演示写作方式，不对应任何现有业务系统。

- 采购专员目前需要逐条归档已完成的采购申请，重复操作较多。
- 本次允许采购专员在采购申请列表中批量归档。允许归档的数据必须同时满足：由当前用户创建、当前状态为「已完成」。
- 未选中记录时，「批量归档」按钮禁用。
- 选中任意不符合条件的记录时，整体中止本次操作，所有选中记录保持原状。提示文本为「所选采购申请当前不可归档，请检查申请状态及操作权限」。
- 全部符合条件时，弹出确认对话，展示本次选中数量。确认文本为「确定归档选中的 n 条采购申请？」。
- 用户取消或关闭确认对话时，不修改记录。
- 用户确认且归档成功后，全部选中记录变为「已归档」，记录归档操作人和操作时间，更新列表状态。成功提示为「已归档 n 条采购申请」。
- 其他条件暂未提供。
