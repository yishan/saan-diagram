# 四象限图

> 用 `python3 scripts/render.py --guide quadrant` 输出本文；起步模板用 `--init <示例名>`。

## 四象限图（`layout: quadrant`）
讲"在两个维度上，这些事项该先做哪个"。
- **坐标轴**：`x` / `y` 写 `{label, low, high}`，事项坐标都用 0–10 打分。象限编号：q1 右上、q2 左上、q3 左下、q4 右下。每个象限可以写 `{label, note}`，`note` 写行动建议（"优先做"）。
- **焦点**：`focus: q1` 给优先象限铺主色浅底；`core: true` 标重点事项（主色圆点），≤3 个。
- **迁移**：事项写 `from: [x, y]` 就画出"现状 → 目标"的虚线箭头，适合讲"通过什么投入把它从攻坚区推到优先区"。
- **标签**：自动在圆点右 / 左 / 上 / 下找空位，并保持在象限内。四周都放不下时报 Q2。
- **选边规则（Q3）**：事项坐标正好落在 5（分界线）上会报错。四象限的价值就在于逼人做取舍，压线等于没打分。
- **洞察用法**：60% 以上的事项挤在同一个象限时，图例下方会提示"评分可能没拉开"。这通常说明打分标准有问题，而不是事项真的都一样重要。

```yaml
layout: quadrant
x: {label: 落地可行性, low: 难, high: 易}
y: {label: 业务价值, low: 低, high: 高}
focus: q1
quadrants:
  q1: {label: 优先做, note: 价值高、好落地}
  q2: {label: 攻坚储备, note: 价值高、难度大}
items:
  - {label: 招标文件智能生成, x: 7.5, y: 8.2, core: true}
  - {label: 智能辅助评审, x: 3.2, y: 8.8, from: [2.0, 8.6]}
```
