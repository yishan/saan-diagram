# 里程碑时间线

> 用 `uv run scripts/render.py --guide timeline` 输出本文；起步模板用 `--init <示例名>`。

## 里程碑时间线（`layout: timeline`）
讲"关键节点什么时候到、现在走到哪、偏了多少"。阶段是轴上方的条，里程碑是轴上的菱形，名称和日期挂在轴下方，放不下时自动错行。
- **刻度**：月份标签在轴上方；跨度超过 18 个月自动改为季度。`start` / `end` 不写就按内容自动取整到月。
- **状态**：只有 `status: done` 表示已完成；`pending` 表示未完成；省略或 `unknown` 表示待确认。`today` 只定位今天线及计算明确未完成节点的逾期，不能由日期推断完成。`core: true` 标关键节点（主色），≤3 个。
- **计划 vs 预测**：里程碑同时写 `plan`（原计划）和 `date`（实际或预测）时，画出原计划的虚线菱形和带天数的偏移箭头。图例下方会汇总"延期 N 个，累计 X 天，最大是哪个"；如果最大延期之后的节点都没写 plan，还会提醒"是否顺延需核实依赖与缓冲"。这正是周报里最容易被藏起来的信息。
- **预算**：≤15 个里程碑、≤8 个阶段，标签最多错 3 行（TL2）。超出说明这是排期表，不是里程碑，该用甘特图。

```yaml
layout: timeline
start: 2026-03                    # 可省略：按内容自动取整到月
end: 2027-03
today: 2026-10-22                 # 可选：今天线，不推断完成状态
phases:
  - {label: 开发与集成, from: 2026-06, to: 2026-10}
  - {label: 试点运行, from: 2026-11, to: 2027-01, core: true}
milestones:
  - {label: 财务系统联调, status: done, date: 2026-09-25, plan: 2026-08-31}   # plan ≠ date → 画偏移
  - {label: 试点上线, status: pending, date: 2026-11-20, core: true}
```
